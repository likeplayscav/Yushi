# 离线打字体验回放

本目录的 50 个任务在首次回放之前冻结，来源是本仓库手写的姓名与语句样例，加上简拼、错拼、退格、中英混输、生僻姓名和标点任务。没有第三方语料，也不把答案写进词库。`reference.json` 来自同一产品数据下的完整候选对照模式；文件只记录目标名次和完成情况，不参与引擎查询。

```sh
cargo build --release --locked -p qingjian-cli
python3 tools/eval/experience.py --binary target/release/qingjian-cli --output target/experience/check
```

每次使用新的输出目录。Windows 上二进制名加 `.exe`，Python 可用 `python`。安装脚本会先编译 CLI 并运行此检查，通过后才构建产品；直接执行 `cargo build` 不会启动体验回放或网络任务。

模拟者逐键查询，每个任务使用独立内存学习器；最终在实际候选中选择目标的最长前缀。普通模式先浏览额度内的候选，找不到时通过候选菜单的“按单字选”路径继续；完整候选对照模式可持续翻页。选词通过真实 `Engine::commit`，记录实际消费的拼音；英文只在原始字母等于目标剩余文字时执行 `take_raw`。单字视图持续到本轮组句结束。这里的选词策略是固定回放假设，不等同真人行为分布，也不测鼠标移动距离或真实应用的 TSF 交互。

输出的 `replay.json` 包含每次按键的首选、最终候选、选词序号、剩余拼音、翻页数、菜单操作次数与查询延迟，失败任务也保留。两次相同状态查询必须一致；打下一个字母后合理改变首选不扣稳定分。每次翻页按一个操作计，每次选择按一个操作计，切视图按右键和点击两个操作计。失败任务的完成与效率均计零。

评分为 100 分：首选 30、前五命中 10、任务完成 15、操作效率 10、学习及跨输入交互 20、同状态稳定性 10、响应速度 5。效率是每个成功任务 `min(1, (输入字母数 + 1) / 实际操作数)` 的平均；响应项为 `5 × min(1, 10ms / P95)`。延迟是本地静态候选查询耗时，取决于机器；后台神经模型与云服务不在这个分值内，发布流程另跑真实模型评测。

分数用于观察变化，发布门槛独立判定：原有每条 Top-1 / Top-5 命中和完成不能回退，所有学习/隐私/重载/编辑检查必须通过，同状态候选必须稳定，总操作数不能超过完整候选基线的 105%。不按一个总分掩盖学习功能失效，也不删除难题提高分数。首选命中与完成率不同：通过手动选字完成一句话，不算预测正确。

响应门禁采用宽于评分目标的 P95 ≤ 50ms、单次 ≤ 1000ms，给不同编译机留出余量，同时拦住明显卡顿。与模型推理、真实应用窗口绘制的耗时分开看。

隔离的九项交互检查覆盖：`m` 选“吗”后的即时首选、落盘重开、私密输入、关闭学习、删掉误选重打、回车原样上屏、退格编辑、切换输入框、丢弃私密组句。它们使用真实 `FrequencyLearner`，只在报告目录建立临时学习文件。

比较额度可加 `--word-limit 9` / `18` / `27`；完整列表加 `--all`。`--baseline` 只在输出目录生成对照文件，不覆盖仓库基线；更新基线需要人工核对任务、数据指纹和逐条差异。报告同时保存二进制、词库、补充词库、语料与数据锁的 SHA256。
