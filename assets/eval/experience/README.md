# 离线打字体验回放

本目录共 131 个任务。原 50 条姓名、语句、简拼、错拼、退格、混输等任务保持不变；`extended.json` 新增 24 个三/四字常用短语，每个覆盖全拼、简拼、中途误触后退格重输，再加三组连续聊天、办公、中文/英文切换会话的 9 条任务。短语覆盖“等一下”“办公室”“注意安全”“会议记录”等，每种长度各 12 个，全部在首次回放前冻结。没有第三方语料，也不把答案写进词库。

`reference-v2.json` 保留原 `reference.json` 的 50 条结果，扩展结果取自首次造词修复前的引擎。旧基线仍保留便于审计；新增的 `zyaq` → “注意安全”未命中且原模拟者未完成，失败样本照录。新的模拟者会取消后改全拼补救，门禁要求所有任务最终完成，但初次 Top-1 / Top-5 仍按简拼结果计。基线只记录名次和完成，不参与引擎查询。

```sh
cargo build --release --locked -p qingjian-cli
python3 tools/eval/experience.py --binary target/release/qingjian-cli --output target/experience/check
```

每次使用新的输出目录。Windows 上二进制名加 `.exe`，Python 可用 `python`。安装脚本会先编译 CLI 并运行此检查，通过后才构建产品；直接执行 `cargo build` 不会启动体验回放或网络任务。

模拟者逐键查询，独立任务使用新的内存学习器，同名连续会话保留上下文；按产品默认设置暂存已选部分，直到选完才整段上屏。最终在实际候选中选择目标的最长前缀。普通模式先浏览额度内的候选，找不到时通过“按单字选”继续；新短语的简拼任务在单字三页内仍找不到时取消组句，改用冻结的全拼再打，取消、重打、翻页与选词均计入总操作数，初始预测名次不变。补救轨迹放在 `retry` 中。完整候选对照模式可持续翻页。选词通过真实 `Engine::commit`，记录实际消费的拼音；英文只在原始字母等于目标剩余文字时执行 `take_raw`。这仍是知道目标的固定模拟者，不等同真人行为分布，也不测鼠标距离或真实应用的 TSF 交互。

输出的 `replay.json`（schema 2）包含每次真实键流（退格为 `\b`）、首选、候选、选词序号、剩余拼音、翻页数与延迟。`query_ms` 只收首次查询，重复热查询另放 `repeat_query_ms`，仅用于稳定性检查；`event_ms` 包含推入/退格/选词及随后的查询，避免漏掉提交与学习耗时。任务开始的词库加载、模型推理、绘制、IPC 不在此计时内。两次相同状态查询必须一致；下一个字母导致首选变化不扣稳定分。每次翻页/选择各计一个操作，菜单切视图计两个操作；失败任务完成与效率均计零。

评分为 100 分：首选 30、前五命中 10、任务完成 15、操作效率 10、学习及跨输入交互 20、同状态稳定性 10、响应速度 5。效率是每个成功任务 `min(1, (目标输入字母数 + 1) / 实际操作数)` 的平均，修正错键也扣分；响应项为 `5 × min(1, 10ms / 事件P95)`。延迟是本地静态引擎耗时，取决于机器；后台神经模型与云服务不在分值内，发布流程另跑真实模型评测。扩展了题目和计时口径，v2 总分不能与旧 50 条总分直接比较，应同时看分场景命中、额外操作和延迟。

每条键流按 50ms（快打）或 80ms（普通）间隔虚拟到达，使用实测事件耗时估算单线程处理队列的等待时间；不通过 sleep 混入人为等待。报告记录 P50/P95/P99/最大值、超过 16.67ms 和 50ms 的比例、排队 P95/最大值，以及最慢的 20 个输入前缀。这个估计用于识别引擎是否来不及处理，不是 Windows 按键到屏幕延迟的实测。

分数用于观察变化，发布门槛独立判定：原有每条 Top-1 / Top-5 命中和完成不能回退，所有学习/隐私/重载/编辑检查必须通过，同状态候选必须稳定，总操作数不能超过冻结基线的 105%（旧 50 条完整列表对照与新增 81 条首次普通列表回放之和）。不按一个总分掩盖学习功能失效，也不删除难题提高分数。首选命中与完成率不同：通过手动选字完成一句话，不算预测正确。

响应门禁要求事件 P95 ≤ 50ms、单次 ≤ 1000ms、虚拟排队 P95 ≤ 50ms；另拒绝查询异常和任何未完成任务。给不同编译机留出余量，同时拦住明显卡顿。与模型推理、真实应用窗口绘制的耗时分开看。

隔离的十八项交互检查覆盖：原十一项 `m` 学习/已有历史/重载/隐私/编辑检查，以及 2/3/4 字词首次逐字造词、简拼造词落盘后全拼召回、私密/关闭学习不造词、未完成组句取消不造词。使用真实产品词库与 `FrequencyLearner`，只在报告目录建立临时学习文件。

比较额度可加 `--word-limit 9` / `18` / `27`；完整列表加 `--all`。`--baseline` 只在输出目录生成对照文件，不覆盖仓库基线；更新基线需要人工核对任务、数据指纹和逐条差异。报告同时保存二进制、词库、补充词库、语料与数据锁的 SHA256。

产品数据升级到 `data-v10` 后，主词库指纹未变，更新数据锁与英文词表指纹。131 条原有期望、最初 50 条结果和 1,801 次操作的基线保持不变；在 InstaBox 复测全部完成，实际 1,761 次操作，逐条 Top-1 / Top-5 与完成率无回退。`reference.json` 与 `reference-v2.json` 只同步数据指纹，不用新结果替换旧期望。
