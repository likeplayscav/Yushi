# 输入准确度、运行资源与安装包优化

基线：`b0b52093`，产品数据按 `data-v9` 的锁定 SHA256 下载，Rust 1.96.0 release 构建。优先 Windows 使用场景，共享引擎的改动覆盖所有平台。

本轮代码和构建方案已实施，可复现实测及验证边界见 [优化结果](../notes/input-efficiency-2026-11-05.md)。

## 验证口径

- 准确度：现有 input-quality 1,444 条、daily-reading 完整集及其独立留出分组、补充词库能力集。正常输入、简拼、错拼、Top-1 / Top-5 和字符错误分别报告；不向词库写入评测答案。
- 延迟与资源：固定 15 组逐键输入，覆盖正常句子、中英混输、错误和重复声母；release 运行三轮，保存阶段耗时、首选、CPU 时间及峰值 RSS。CLI 标注整份候选，数值不等同于 Windows 桌面端到端延迟。
- 模型：用受控的阻塞模型复现输入切换、关闭模型与清空组句后是否继续做过期工作；实际模型只在数据指纹一致时比较。
- 包体：区分安装包压缩大小与安装展开大小。当前公开 0.3.2 Windows 包为 88,888,970 字节，已核对 SHA256；当前源码多了独立剪贴板，不能将两版本差值当成本次优化收益。

## 实施顺序

1. 减少词图重复搜索与短时分配：只有一种可选切分时直接采用它；单前驱路径不建立临时 Vec。保持候选语义，逐条对比基线输出。
2. 核查多词库合并后的候选裁剪：相同文字的词条不能重复占据有限名额；用不同词频的重叠词库验证，再检查完整准确度集。
   同时修复连续上屏后的整句评分：起始词沿用 `CommitChain` 的前两个词，路径第二个词也保留跨输入段的三元上下文；断链后恢复句首。
3. 让选词模型停止过期任务：新输入或会话边界使旧任务失效，卸载后不继续剩余批次，旧结果不能顶掉当前缓存；正常重复查询与收到模型结果后的重查仍可收敛。
4. 将旧 WinUI 设置及 Windows App Runtime 改为可选兼容构建，标准包使用现有的共享设置程序；保留可显式构建的旧版，不裁减词库、学习语言或 32 位 TSF。菜单按实际安装内容显示。
   release 开启 ThinLTO、单 codegen unit 与符号表剥离，以实际可执行文件大小及逐键基线验证取舍；保留 panic 展开。
5. 保存前后准确度、逐键耗时与资源报告，更新开发和用户文档；全 workspace 测试、fmt、Clippy、Windows 交叉检查以及打包逻辑检查通过后提交。

独立剪贴板、云联想和本地模型均已有开关；本次不靠默认启用网络、增大模型或删除常用输入能力换指标。Windows 安装与真实宿主交互需在 Windows 原生环境补验，Linux 结果明确标注其适用范围。
