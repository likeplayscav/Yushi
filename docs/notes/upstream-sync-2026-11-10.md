# 2026-11-10 同步青简主线

从本 fork 的 `ed6b3d3f` 合入 `qingjian-team/qingjian` 的 `da5d21b7`，包含 48 个新提交。版本保持 `0.3.4-dev`，这次仅同步源码，不发布安装包。

## 上游变化

- 词库、释义表、英文词表、音标和码表迁到 `qingjian-dicts`，支持 `.qjz` 下载、队列、删除和 TSV 导出；升级时补回旧版本已启用的词库。
- 停用 `data-vN`，词库由 `dicts.lock` 固定，语言模型与含章·通变由 `models.lock` 固定，下载时核对哈希。
- 用户数据分成 `learning/`、`records/`、`custom/`、`downloads/`、`cache/`，启动时迁移旧文件。
- 英文 IPA 音标、屏蔽词、关闭基础词库的词条、笔顺与部件混合查字、日期快捷输入，以及 Linux AppImage。
- 更新 candle-core、jiff、memmap2、plist 与手动 CI 的 Rust 缓存依赖。

## 本 fork 的兼容处理

保留竖版候选在光标上方倒置、拼音行在下方、方向键与鼠标位置对应，以及最近选择偏好、候选视图切换、Windows 搜索宿主和隐私隔离改动。Windows 启动、热加载与 CLI 继续追加内置补充词库；屏蔽词先过滤，最近选择只提升仍在候选中的项。

最近选择文件 `user-preferences.tsv` 及备份跟随其他学习数据迁到 `learning/`。迁移测试核对内容与重复启动；Windows 路由测试用真实迁移后的学习目录检查改选与重启记忆。安装保留检查接受新旧布局，并继续逐字节核对内容。

回放改用当前随包的英文 `.qj` 和默认附加词库，报告分别保存 `dicts.lock`、`dicts-extra.lock`、`models.lock` 的哈希。安装脚本保留 Python 解释器覆盖、可选旧设置与既有运行库打包方式，更新取数步骤和测试夹具。所有 GitHub 工作流仍只有手动入口，编译验证在 InstaBox 执行。

上游不再默认随包通用扩展词库后，姓名语句抽测出现 6 项 Top-5 回退。继续加载原通用扩展词库能消除这 6 项回退，因此本 fork 的 Windows 包与回放保留它，改从官方词库仓库下载 `general-v1.0.0`。`dicts-extra.lock` 固定其哈希，官方随包清单 `--update` 不会覆盖该扩展锁；安装包同时带上来源与 CC BY-SA 4.0 许可声明。

上游删除词库源文件后，只保留补充词库清单中固定哈希的历史输入及 THUOCL 许可证，供离线复现与来源核验；不把这些历史输入用于当前主词库打包。补充词库内容、冻结评测题目和期望排名均未修改。

上游时间快捷项新增毫秒后，`sj` 前缀的连续查询会更新时钟文本。回放仅对 `sj` / `shijian` 的 `Shortcut` 文本放行刷新，仍检查数量、槽位、类型和所有普通候选；非时间快捷项保持严格比较。报告保存每次刷新的前后值，新增测试验证时间变化不能掩盖词序、候选数量或类型变化。
